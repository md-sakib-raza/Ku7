# THE 90I NEWS

> सच | सटीक | निर्भीक

A fully responsive, Hindi digital news portal with GitHub Contents API-powered Cloud CMS and unique SEO permalinks.

## Features
- **Cloud CMS:** Admin syncs directly via GitHub API into `data/90i-data.json`.
- **Pages:** Home, Article, Category, Search, Gallery, Video, E-Paper, About, Contact, Privacy, Terms, Admin.
- **Hosting:** Optimized for static hosting on GitHub Pages.
